# critique — translating the owner's review language

When the owner critiques in their own words, this table is the diagnosis and the
first moves. Their phrasing is the trigger: never ask them to restate it in
design terms.

| Owner says | Problem | First moves | The model's error pattern |
|---|---|---|---|
| "Don't know where to look" | Focal point | One dominant element; place everything else deliberately around it; remove competing elements; directional imagery pointing at it | Adds a second focal element to "balance" the composition, which destroys the first |
| "Too generic" | POV missing | Drop the trend and the industry cliché; commit to one unique point of view; get bolder | Trades one trend for a fresher trend — brutalist for gradient-SaaS — and reports the new reference set as a point of view; nothing about the page argues anything |
| "Feels flat" | Layering | Add contrast, overlapping elements, subtle elevation; build a real foreground/background relationship | Adds a drop shadow, blur, or border-glow and calls it depth; no element's stacking or overlap actually changes |
| "Lifeless" / "empty" | Energy | Asymmetry; tighter image crops; diagonal movement and rhythm; more expressive imagery | Reads "empty" as literal emptiness and fills the ground with more cards, more copy, a decorative flourish — busier and still inert, when the fix was tension in what's already there |
| "Doesn't feel branded" | Character | Play with the type; a unique image direction; personality through icons (custom, not a Lucide default); build a shape language — think deeper than an average AI would | Applies brand as a token pass — accent hue and font family swapped globally — while the icons stay Lucide defaults, the imagery stays stock, and no shape language is ever defined |
| "Everything is equally important" / "lack of focus" | Hierarchy | Reduce competing colors; remove unnecessary text styles, or add ones that make the hierarchy legible; kill excessive borders | Promotes the one element it judges most important instead of demoting the rest; relative contrast is unchanged and every element ends up louder |
| "They look separate even though they're talking about the same thing" / "merge these two sections" (REPEAT ×3, 2026-09-02) | Register boundary | Delete the second register — ground, plate family, head style — so both halves share one card family on one ground | Nests the block structurally (h3, same parent) and leaves its token-flipped sub-band, texture, and margin; a register change IS a section boundary, so the eye still sees two |
| "Doesn't look premium" | Confidence | Restraint — Apple-minimal, clean, polished; a confident spacing system; better imagery; consistency | Equates premium with a signifier set — dark ground, glass panels, a serif headline, uniformly more whitespace — while the inconsistent spacing scale that actually read as cheap survives untouched |

## Standing rules when improving anything finished

- **Edit before decorating.** On a busy, already-built page, the first pass
  is what to delete, remove, or hide — never what to add. Get the vision
  concise, then polish.
- **Break consistency on purpose when clarity demands it.** A screen with a
  different job or risk level earns a deliberate pattern break — that's a
  senior call, not a defect. Consistency that hurts clarity loses.
